## Intisari Pembelajaran

### 🔑 Pelajaran Kunci
- **Data > Algoritma** — Data bersih lebih penting dari model canggih
- **Akurasi bukan segalanya** — Precision, Recall, F1 bergantung konteks bisnis
- **Visualisasi = komunikasi** — Bukan sekadar grafik cantik
- **Preprocessing wajib** — Tanpa encoding & scaling, model gagal

### 🛠 Tools yang Dikuasai
- **Manipulasi**: Pandas, NumPy  
- **Visualisasi**: Matplotlib, Seaborn  
- **ML**: scikit-learn (Regresi, Klasifikasi, Clustering, Apriori)  
- **NLP**: TF-IDF, Logistic Regression  
- **DL Dasar**: Neural Network dengan TensorFlow/Keras
